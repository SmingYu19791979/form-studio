# FORM · 产品布景工作台

开发仓库：[SmingYu19791979/form-studio](https://github.com/SmingYu19791979/form-studio)（私有，main 分支）。在另一台电脑先登录 GitHub 并克隆仓库，再阅读 AGENTS.md、DEVELOPMENT_HANDOFF.md 和 GITHUB_SYNC.md。此仓库根目录就是完整工作台源码，可直接运行下方启动命令。

便携使用见 [Mac / Windows 使用说明](先读我-双平台使用说明.md)。Mac 双击 Start-Mac.command，Windows 双击 Start-Windows.cmd；需 Python 3.11+。本地命令行运行（保持窗口开启）：`python3 launch.py`，浏览器打开 http://localhost:8765/。也可双击 start-studio.command 启动。需要本机已安装并登录 Codex；后台沿用现有 Codex 模型与连接配置，消耗相应模型用量。普通静态服务器无法生成新品。

## 选图后直接在场景中生成

- 点击“图片生成产品 / 图片生成”，选择 PNG / JPG / WEBP 后，自动识别同款与容量，创建三维产品、专属材质和毫米尺寸并立即加入场景。没有中间资料确认窗口；不会导出或下载研究JSON文件。
- 当前已建立的产品：致美面霜50ml、雪纱隔离乳No.40 30ml（包含用户高清斜角图）、小蓝盾洁颜膏30g。产品图片、模型创建器、来源档案和尺寸共用 product-catalog.js 注册表。
- 净含量版本必须匹配，30g不显示为30ml，150g或100ml不能默默替换成30g或50ml。
- 输入图片不是照片平面贴进场景；已研究模型有独立部件、物理材质、真实厚度和独立印刷层。参考图来自用户与逐款实际查询的品牌资料，未知背标、开盖与真实材料参数保留标注。
- 资料档案改到生成后的“参考档案与产品还原”按钮中，供需要时核对、校正毫米尺寸和重建模型。
- 未登记新品自动进入本机 Codex 建模任务：看图识别 → 实际联网查找同版资料 → 返回专属部件轮廓、PBR材质、印刷与毫米尺寸 → 校验 → 直接加入场景。无需在对话里逐款补登记。源图与文件名作为参考证据，不作为代理指令。
- 进度显示真实检索状态、检索次数与耗时。可取消、重试；后台任务与浏览器待入场请求分别持久保存，刷新后续接，完整布景保存成功后才清理待入场请求，避免丢失和重复添加。
- 新品几何由数据描述：旋转曲面、截面放样、圆角实体等可组合独立部件，分区物理材质和独立印刷层。不会执行模型返回的JavaScript。参考不足会报错，未知背标不编造；单张图加公开资料仍是近似还原，不能等同实物扫描。
- 每个生成对象保存完整研究来源、未查证项、模型配方与动态尺寸档案。净质量g与体积ml分开记录；未找到实测外尺寸时明确标为估算，可输入一边实测尺寸等比标定。不同产品共享1单位=25mm。
- 本机任务通过已登录Codex向其现有模型服务发送产品图与研究任务。代理只开放看图、联网检索和结构化结果，关闭命令执行、插件、MCP工具及子代理。服务只监听127.0.0.1，拒绝跨站提交，不暴露本机凭证；原图与诊断记录保存在不对网页开放的runtime/jobs目录中。
- 多张文件按顺序生成，避免重叠导入会话；支持GLB内嵌纹理与OBJ。
- 研究笔记见 research/laneige-50ml-reference-notes.md、research/skin-veil-40-reference-notes.md、research/water-bank-foam-30g-reference-notes.md。

## 地面材质与布景道具 · 1.1.0

- 顶部“＋ 道具”打开场景面板，可选择立方体、圆角方块、长方形展台、圆柱展台、球体、拱形展台、阶梯展台、飘带和蝴蝶结。
- 道具是有体积的 Three.js 几何，沿用 1 场景单位 = 25 mm。选中后在“对象”中分别设置宽、高、深和颜色；可继续移动、旋转、整体缩放、复制、贴地、移除及撤销重做。
- “场景”面板提供哑光、亮面、大理石、混凝土、木纹和织物。纹理可按 50–2500 mm 调节覆盖宽度和方向，并保留地面颜色、可见性和阴影控制。
- 地面使用随应用附带的独立颜色、OpenGL 法线和粗糙度贴图，不依赖运行时联网；道具几何和缎带材质会完整写入布景文件，换电脑打开无需额外素材。丝带与蝴蝶结具有实际宽度和厚度。
- 旧布景未包含地面材质字段时默认沿用原哑光地面。保存、恢复、撤销重做和 PNG 导出均保留新增布景功能。
- 回归增加 `node --test qa/stage-props.test.mjs`，验证几何、物理尺度、独立尺寸、颜色、布景往返恢复及丝带闭合体积。

## 场景编辑

- 移动、旋转、缩放、自由拖动、精确数值、批量复制、隐藏、移除、贴地、撤销重做。
- 灯光方位/仰角/强度/颜色、补光、环境反射、阴影柔化、曝光。
- 透视/正交、焦距、距离/视野、环绕、俯仰；右键平移，滚轮缩放。
- 背景、地面、网格、透明 PNG、1600/2400 px 长边输出。
- 自动保存在 IndexedDB，并镜像到应用文件夹的 runtime/current-project.json；空浏览器会从该文件恢复。“保存布景”导出含素材、原图、参数、摆放、灯光、相机的完整 JSON，可重新打开。清理浏览器数据会清除自动保存，请保留布景文件。
- 最多 30 个场景对象；单产品文件 80 MB，布景文件 100 MB。

快捷键：Q 观察，W 移动，E 旋转，R 缩放，F 适应画面；工具栏可聚焦选中产品，Ctrl/Cmd Z 撤销，Ctrl/Cmd Shift Z 重做。

## 验证

打开 /parts-qa.html，检查独立部件、分区材质、微观纹理、可调盖高以及原面霜专属模型、顶盘、印刷和材质配方。内置面霜源于用户提供的两张图片，背面和底部仍有简化推测，并非实物扫描。

## 包装尺寸与容量

- 全部已研究产品共享毫米尺度：1 场景单位 = 25 mm；不再把每个产品的最长边统一到 2.7。
- 净含量与外部包装体积是两个数据。先确定同款 / 容量版本，再用该版本的毫米尺寸标定几何。不同外形之间不能只凭 ml 比值换算外形大小。
- 面霜以零售商标注宽 63.1 mm 标定，并保留主图比例，模型约宽63.1 / 高54.5 / 深63.1 mm；非实测。
- 隔离乳仅有外包装长边约112–117 mm 线索，瓶高暂估110 mm，按图片比例得到约宽36.9 / 高110 / 深25.8 mm。此为外形估算，不能宣称已验证的实物尺寸。
- 对象档案与对象面板都显示净含量、毫米尺寸、依据与可信状态。输入任意一边的实测值等比标定，记录“用户输入尺寸”。对象根节点的布景缩放与包装基准分开，面板显示缩放后的尺寸；“恢复参考尺寸”同时回到100%布景缩放。
- 旧布景首次迁移：只更新已识别产品，原位置、旋转、可见性、材质和身份保留；此前的显示缩放归100%，消除拉伸。版本标记使后续重开不重复缩放；自定义标定可随布景保存。
- 尺寸来源及推断见 research/physical-dimensions-notes.md。尺寸逻辑验证：node --test qa/product-scale.test.mjs。

直接生成回归检查：`node --test qa/product-import.test.mjs qa/product-scale.test.mjs qa/generated-model.test.mjs` 与 `python3 -m unittest discover -s qa -p 'test_*.py'`。另需在浏览器用未登记原图实测联网研究、直接加入、斜视、刷新保存、档案查看与材质透明度。后台建模最长20分钟，单张请求图片小于8MB，最多6个排队或运行任务，按顺序生成。

### 圆角参数与材质修复（2026-10-15）

- 薄片、泵嘴等圆角部件统一按最小厚度的49%限幅，和Three.js构建器一致；不再因一个局部圆角过大而拦截整个产品。仍拒绝零尺寸、负尺寸、非有限值及不完整研究数据。
- 再次导入或重试失败图片时，优先校验并复用该任务已经完成的真实联网研究结果；保存原始代理输出及圆角调整记录，不重复消耗整轮建模。
- 拉丝纹理改为低幅度一次采样，保持原有底色，避免重复叠加使金色变灰、出现粗条纹。已保存的自动生成模型会在刷新时更新这层纹理，保留摆放和材质调节参数。
- 实测致美精华20ml与40ml原始失败图片直接生成入场，并刷新验证保存。

### 材质与节日场景 · 1.2.0

- 顶部“节日场景”进入 618 年中盛典、双十一购物季、圣诞礼遇、新年纳福。每套配好地面、背景、灯光和五个独立三维装饰，包括立体数字、礼盒、圣诞树、灯笼、折扇和缎带。
- 原有产品和手动道具的位置、旋转、缩放保持不变；切换只替换上一套主题装饰。复制的装饰成为个人道具，后续切换不会移除。对象达到30个上限时整套拒绝添加，不会丢失原布景。
- “移除主题 · 恢复原布景”还原首次应用前的环境参数和相机，保留用户之后对产品的编辑。主题、原布景参数、所有装饰支持自动保存、JSON导出、刷新恢复、撤销和重做。
- 大理石、混凝土、白橡木和蓝灰亚麻使用随包附带的1K PBR贴图；基础颜色使用sRGB，法线和粗糙度保持线性。可调整覆盖宽度、方向、粗糙度、细节强度和染色，或恢复该材质推荐参数。来源、许可证和校验值见 dist/assets/materials/SOURCES.md 与 sources.json。
- 旧版条纹地面首次加载会升级推荐尺度，保留自定义染色；新版保存后保留用户调整。白色染色保留原材质颜色。
- 修正整体缩放破坏独立尺寸比例的问题；阴影范围跟随当前对象，长焦与竖幅画面使用投影边界取景，扩大地面避免大场景露出边缘。PNG导出等待当前地面纹理就绪。
- 增加 `node --test qa/scene-surfaces.test.mjs`：纹理通道/校验值、异步切换竞态、载入失败、旧数据迁移、主题JSON往返、产品保留、30对象原子校验、比例缩放及长焦取景。
